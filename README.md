# SURYA TEAM

Pierwsza iteracja statycznej strony biura rachunkowego SURYA TEAM.

## Uruchomienie lokalne

W katalogu projektu:

```powershell
python -m http.server 4173
```

Następnie otwórz `http://localhost:4173/`.

Strona nie wymaga bundlera ani instalowania zależności. Style są w `assets/styles.css`, a interakcje w `assets/main.js`.

## Do uzupełnienia przed publikacją

- podmiana domeny `suryateam.pl` na właściwy adres, jeśli będzie inny;
- podpięcie prawdziwej skrzynki / endpointu formularza kontaktowego;
- dodanie finalnych danych kontaktowych i ewentualnego adresu biura;
- weryfikacja tekstów prawnych i danych strukturalnych przez właściciela marki;
- zastąpienie roboczych tematów w sekcji Notatki pełnymi artykułami.
